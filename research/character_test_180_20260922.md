## 效果观察

1. 生图保留了金发、深色外套与暖色酒馆的大体风格，但右侧新增了一个桶，未严格保持原来的物品布局。这张图不直接替换正式场景。
2. 视频抽查第 0、24、48、72、96 帧，可见头部姿态、嘴形与表情变化；但物品发生变化，不能据“大体延续场景”判定场景一致性通过。仅 4 秒样例，也不能证明长时身份一致或动作自然度已经达标。
3. 提示词明确要求无字幕，但视频中仍出现了乱码中文字幕。该项不通过。
4. 目标对白是“先把账册放到干处吧。”，faster-whisper base 在 CPU int8 下自动识别为中文，转录“先把账侧放到干处吧”，有同音字差异，基本匹配。ASR 不能代替音色、自然度及唇音同步的人耳验收。[转录记录](out/character_180_20260922/audio_review.json)。
5. 本轮只要求小幅人物反应、物品保持不动，没有验证搬物品、人物透明层、背景合成或交互中追加指令。

- 权重及项目位于 `/mnt/sv0/sean`，远端可访问。
- 共享虚拟环境的 Python 链接指向本机专有 home 路径，180 不可用；将现有 CPython 3.11 运行时放到 `/mnt/sv0/sean/runtimes/cpython-3.11-ludens`，通过 PYTHONPATH 复用现有依赖，没有改动原环境。

- 生图依赖来自 `ludens-flux`：Torch 2.14.0+cu130、diffusers 0.40.0、transformers 5.16.1。
- 视频依赖来自 `ludens-joyai`：Torch 2.8.0+cu128、transformers 4.57.6；缺少的 OpenCV 单独安装到测试目录的 `extras`。

- 音轨校验在本机 CPU 进行，辅助 ASR 依赖与 base 权重保存在测试输出目录，没有占用本机训练 GPU。

## 对当前设计的意义

生图专门定视觉、视频使用其首帧的路线已经得到一个真实样例。首帧多桶、视频物品变化与乱码说明整幅生成视频不能直接作为交互场景。修正路线是分离人物与透明度，只将人物合成到独立背景和物品层中；需要先去掉当前背景里烘焙的人物，并验证边缘、遮挡及动作衔接。低延迟动态反馈同样尚未解决，不能把这条离线链路直接放回每次操作的等待路径。

## 反馈后补测：独立人物层

复用上述 97 帧视频，使用开源 [Robust Video Matting](https://github.com/PeterL1n/RobustVideoMatting) 的 MobileNetV3 FP32 ONNX 权重分离人物。模型输出前景与透明度，按官方接口逐帧传递循环状态；本次在本机 CPU 运行，限制 4 个计算线程，未占用训练 GPU，也未重新生成视频。

- [人物分离预览](out/character_layers_20260922/character_only_preview.mp4)：灰色棋盘格用于检查人物边缘，该 MP4 本身不透明，且没有混入原音轨。
- [第 48 帧透明 PNG](out/character_layers_20260922/character_048.png)：保留真实 alpha，可用于检查分层素材。
- 处理 97 帧约 10.76 秒，不含会话初始化及模型下载；不代表实时性能。模型文件约 14.2 MiB。[指标](out/character_layers_20260922/matting_metrics.json)。
- 人工查看第 0、24、48、72、96 帧，桶、木箱、账册、毛巾与背景主体已被排除；这五帧右侧 x≥700 区域 alpha 最大值均为 0。该数值只验证指定区域，不代表所有人物边缘均合格。
- 首帧衣服下摆出现明显半透明缺损，其他抽查帧的轮廓更完整，但边缘仍有软化。这是人物分离的可行性样例，尚未通过完整时序、遮挡和正式场景合成验收。

原 Demo 地址后添加 `/static/character-layers-20260922/character_only_preview.mp4` 可预览，本机 80 端口 HTTP 200。当前在线场景未替换，尚需生成去掉 Cassian 的背景底图，再与独立物品层合成。新样片不能证明视频生成延迟已经解决。

### 人物质量验收反馈

Sean 进一步反馈：边缘、转身有问题，整体有些糊。当前“Echo-WM Flash 样片 + RVM 抠像”组合的视觉质量不通过，不作为正式人物效果接入。

对照原视频与抠像结果的第 0、96 帧：原视频末帧脸部与头发细节已有软化；抠像又在首帧明显损失外套下摆与身体轮廓。需区分源视频清晰度、运动中的人物稳定性与抠像误差，不能将所有问题归于其中一个模型。转身的连续自然度以用户播放反馈为依据，静态帧对照不能单独完成该项判断。本轮视频还使用了非官方推荐文本编码器，结论仅针对这次实际配置与样例。

后续质量验证应先看未经抠像的原视频是否满足人物清晰度与动作要求，再在同一段视频上比较人物分离效果。人物首帧可尝试无道具、背景简洁且轮廓清晰的构图，保持酒馆光照与视角；这是待测改进，不能预先承诺解决转身或边缘问题。补背景和正式合成应在人物质量通过后推进。
